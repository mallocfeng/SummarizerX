# SummarizerX v2.3.13

## Highlights
- **Share card facelift:** the generated share image now uses a flatter style with tighter corner radius, cleaner header band, and simplified borders for a modern look.
- **Summary title block:** the summary card now shows the page title before key points, and translates the title to match your output language.
- **Translation cache:** translated titles are cached locally so repeat visits don’t re-translate and feel faster.

## 更新亮点
- **分享卡片焕新**：生成的摘要卡片改为更扁平的风格，圆角更小、标题区更清爽、边框更简洁，整体更现代。
- **摘要标题块**：摘要卡片在要点前展示页面标题，并会按输出语言自动翻译。
- **翻译缓存**：标题翻译结果本地缓存，重复访问无需重复翻译，体验更顺滑。

## Install
1. Download `SummarizerX-v2.3.13.zip` from this release.
2. Unzip the archive (do **not** load the ZIP directly).
3. Visit `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select the unzipped folder.

## 安装步骤
1. 从本次发布中下载 `SummarizerX-v2.3.13.zip`。
2. 解压 ZIP（请勿直接加载压缩包）。
3. 打开 `chrome://extensions`，启用 **开发者模式**，点击 **加载已解压的扩展程序**，选择解压后的目录即可。

Enjoy! 🎉
