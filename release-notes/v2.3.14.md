# SummarizerX v2.3.14

## Highlights
- **Native streaming output:** summaries and Q&A now render token by token instead of all at once.
- **Much faster first response:** perceived load speed improves significantly during summarization and chat.
- **SSE fallback:** automatically switches to non-streaming mode when an API does not support SSE.

## 更新亮点
- **原生流式输出**：摘要与问答支持逐字呈现，不再一次性输出。
- **首帧更快**：摘要与聊天的加载速度明显提升。
- **自动回退**：当接口不支持 SSE 时自动切回传统非流式方式。

## Install
1. Download `SummarizerX-v2.3.14.zip` from this release.
2. Unzip the archive (do **not** load the ZIP directly).
3. Visit `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select the unzipped folder.

## 安装步骤
1. 从本次发布中下载 `SummarizerX-v2.3.14.zip`。
2. 解压 ZIP（请勿直接加载压缩包）。
3. 打开 `chrome://extensions`，启用 **开发者模式**，点击 **加载已解压的扩展程序**，选择解压后的目录即可。

Enjoy! 🎉
