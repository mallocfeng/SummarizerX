# SummarizerX v2.3.15

## Highlights
- **Maintenance release:** version bump for release packaging (no functional changes).

## 更新亮点
- **维护更新**：发布打包的小版本号升级（无功能变更）。

## Install
1. Download `SummarizerX-v2.3.15.zip` from this release.
2. Unzip the archive (do **not** load the ZIP directly).
3. Visit `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select the unzipped folder.

## 安装步骤
1. 从本次发布中下载 `SummarizerX-v2.3.15.zip`。
2. 解压 ZIP（请勿直接加载压缩包）。
3. 打开 `chrome://extensions`，启用 **开发者模式**，点击 **加载已解压的扩展程序**，选择解压后的目录即可。
